# Estimated human workload

These are planning estimates for a learner with the prerequisite programming knowledge who reads the material, implements every exercise, debugs the applications and verifies the results. They are not tracked study time and do not assert that any person actually spent these hours. Individual learning time can vary substantially.

| Part | Central estimate | Plausible range | Included work |
| --- | ---: | ---: | --- |
| 0 | 5 hours | 3-7 hours | Web fundamentals, browser/network inspection and three sequence diagrams |
| 1 | 15 hours | 10-20 hours | React fundamentals, three applications, state and interaction checks |
| 2 | 25 hours | 18-32 hours | Forms, effects, CRUD, HTTP services, country search, weather and error handling |
| 3 | 25 hours | 18-32 hours | Express API, MongoDB, validation, logging, deployment and full-stack verification |
| 4 | 25 hours | 18-35 hours | Modular backend, helper/API tests, user management and token authentication |

Earlier submission entries explicitly described elapsed automation-work estimates. The course submission page currently exposes no edit control for those submitted rows. These human-workload estimates are recorded separately so they cannot be mistaken for measured time.
