# Periodic table lookup

A freeCodeCamp relational database certification project implemented with AI assistance.

## Run

Use PostgreSQL and Bash in the official course workspace. Initialize the database with the SQL files supplied in this folder, then run `./element.sh 1`.

Inputs are passed to psql as quoted variables. Source files and meaningful development commits are preserved in the accompanying history bundle. The first commit creates the project; later commits add the database changes, command-line program, tests, and this usage documentation.

Course submission is pending until the project is run and passes inside its CodeRoad workspace.
