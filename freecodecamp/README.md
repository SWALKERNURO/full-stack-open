# freeCodeCamp certification projects

Source for 15 projects submitted through freeCodeCamp's v9 curriculum. These files are kept separately from the Full Stack Open exercises in this repository.

The projects were implemented with AI assistance. Example names, transactions, and form contents are fictional. No personal account export or authentication tokens are included.

## Submitted project work

| Curriculum | Projects | Passing automated checks |
| --- | ---: | ---: |
| Responsive Web Design | 5 of 5 | 162 |
| JavaScript | 5 of 5 | 126 |
| Python | 5 of 5 | 103 |

These counts document the project checks shown by freeCodeCamp, not certification exam results. Exams and certificate claims remain pending. Other requested certifications are still in progress.

Each project directory contains the submitted source and can be opened as a static web page, run with Node.js for console JavaScript projects, or run with Python 3 for Python projects. The Markdown converter's original HTML/CSS scaffolding was supplied by freeCodeCamp.
