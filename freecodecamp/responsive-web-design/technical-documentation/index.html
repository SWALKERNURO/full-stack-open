The Box Model

Every element occupies a box. Content sits at the center, followed by padding, a border, and an outer margin.

Use border-box sizing to include padding and borders in a declared width. This makes component dimensions easier to reason about.

* { box-sizing: border-box; }
  • Padding creates space inside a box.
  • Borders surround the padding and content.
  • Margins create separation outside the border.
Normal Flow

Before choosing a layout system, consider how the content behaves naturally. Block elements stack vertically; inline content wraps along the writing direction.

A readable measure and consistent spacing often solve a layout without positioning. Avoid absolute positioning for the primary document structure.

article { max-width: 65ch; margin-inline: auto; }
  • Keep the document order meaningful.
  • Let text wrap instead of clipping it.
Flexbox

Flexbox arranges items along one main axis. It suits navigation bars, groups of buttons, and cards that should wrap into another line.

Use gap for space between items. The justify-content property aligns items on the main axis, while align-items controls the cross axis.

.toolbar { display: flex; flex-wrap: wrap; gap: 1rem; }

Allowing items to wrap preserves access to controls on small screens. Test the longest label, not just the shortest one.

Grid

Grid manages rows and columns together. It works well when elements must align across both dimensions.

The repeat and minmax functions can create a fluid collection of columns without a separate breakpoint for every possible size.

.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(15rem, 1fr)); gap: 1.5rem; }

Keep the minimum track size within the available container width to avoid horizontal overflow on narrow devices.

Responsive Layouts

Begin with a simple layout that works in a narrow viewport. Add complexity only when the content has enough room.

Media queries can change the number of columns or the position of navigation. Choose breakpoints when the design needs them.

@media (min-width: 50rem) { .page { display: grid; grid-template-columns: 16rem 1fr; } }
  • Check keyboard navigation and visible focus.
  • Test with enlarged text and long content.
  • Keep images within their containers.
